👥 Usuários do Sistema

Este sistema usa o login seguro do Supabase (mesmo login de todo site confiável, com senha protegida e recuperação por e-mail). Para adicionar uma nova pessoa, entre no painel do Supabase em Authentication → Users → Add user e cadastre com um e-mail real e uma senha (mín. 6 caracteres). Se quiser que o nome dela apareça no sistema (em vez do e-mail), preencha o campo User Metadata com {"nome": "Nome da Pessoa"} ao criar o usuário.
